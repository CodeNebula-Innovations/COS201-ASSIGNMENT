# COS201-ASSIGNMENT
COS 201 Week 3 Assignment

Overview

This repository contains the Java programming assignments for Week 3 of COS 201 (Computer Programming I).

The assignment focuses on basic Java programming concepts, arithmetic operations, user input, and program execution.

Programs Included

1. SimpleCalculator.java

A simple calculator program that performs basic arithmetic operations, including:

- Addition
- Subtraction
- Multiplication
- Division

2. AverageCalculator.java

A program that calculates the average of numbers entered by the user.

3. ItemCost.java

A program that calculates the total cost of an item based on its price and quantity.

Requirements

To run these programs, you need:

- Java Development Kit (JDK) installed on your computer.
- A Java-compatible code editor or terminal.

How to Run the Programs

Step 1: Clone or Download the Repository

Clone this repository to your computer or download it as a ZIP file and extract it.

Step 2: Open the Folder

Open the assignment folder in your preferred code editor or terminal.

Step 3: Compile the Program

To compile a program, run the following command in your terminal:

javac SimpleCalculator.java

Replace "SimpleCalculator.java" with the name of the program you want to compile.

Step 4: Run the Program

After compiling, run the program using:

java SimpleCalculator

Replace "SimpleCalculator" with the name of the program you want to execute.

Running Each Program

Simple Calculator

javac SimpleCalculator.java
java SimpleCalculator

Average Calculator

javac AverageCalculator.java
java AverageCalculator

Item Cost Calculator

javac ItemCost.java
java ItemCost
